# Customer Segmentation using RFM & K-Means

## Objective
Analyzed e-commerce customer transaction data and segmented customers based on Recency, Frequency, and Monetary (RFM) values.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Jupyter Notebook

## Project Workflow
1. Data cleaning and preprocessing
2. Removed missing customer records
3. Calculated total transaction amount
4. Performed RFM analysis
5. Standardized RFM features
6. Used the Elbow Method
7. Applied K-Means clustering
8. Analyzed customer segments
9. Created visualizations and business insights

## Customer Segments
- Regular Customers
- At-Risk / Low-Value Customers
- VIP / Champions
- High-Value Loyal Customers

## Key Insights
- VIP/Champion customers showed very high purchase frequency and spending.
- High-Value Loyal customers showed recent and frequent purchases.
- Regular customers represented the largest customer group.
- At-Risk/Low-Value customers had relatively low frequency and spending.

## Business Recommendations
- Reward VIP and high-value customers with loyalty offers.
- Use personalized campaigns for regular customers.
- Run re-engagement campaigns for at-risk customers.
- Monitor high-value customers to improve retention.
